# Fallback Images

This folder contains placeholder images used when Instagram/Unsplash images are not available.

## Structure

```
fallback_images/
├── manicuristas/     ← Images for nail/manicure businesses
│   ├── hero.jpg      ← Hero section (1200x800px recommended)
│   ├── about.jpg     ← About section
│   ├── gallery_1.jpg ← Gallery images
│   ├── gallery_2.jpg
│   └── ...
├── generic/          ← Generic fallback for any niche
│   ├── hero.jpg
│   ├── about.jpg
│   └── ...
└── README.md
```

## Adding Images

1. Create a folder for each niche (matching the niche names in your Excel)
2. Add 6-8 high-quality images per niche
3. Recommended image sizes:
   - Hero: 1200x800px
   - About: 800x800px
   - Gallery: 800x600px

## Image Sources

You can get royalty-free images from:
- [Unsplash](https://unsplash.com)
- [Pexels](https://pexels.com)
- [Pixabay](https://pixabay.com)

Make sure to check licenses for commercial use.
